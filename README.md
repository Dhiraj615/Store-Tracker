# Store Tracker - Stock, Sales & Credit for Small Stores

🔴 Live Demo: https://dhiraj615.github.io/Store-Tracker/

### About Me
B.Tech IT Graduate (2026) | LNBCIEM, Raigaon | dhirajdisale007@gmail.com

### Problem I Found
I interviewed 9 retail store owners in Pune/Satara:
- 7/9 track stock in notebook
- 6/9 lose track of credit (udhaar)
- Average 45 mins/day on daily accounts

### Solution I Built
One-file app (HTML, CSS, JS, localStorage) - works offline on mobile:

- **Dashboard** - Today's sales, items to restock, credit pending, 7-day sales chart
- **Make Bill** - Add items, check stock live, print thermal receipt
- **Stock** - Add items with low-stock alert
- **Credit** - Track who owes you, record payments

### Impact
- 3 stores used it for 2 weeks, 2 still active
- Accounting time: 45 mins -> 15 mins (self-reported by 2 stores)

### Tech Stack
HTML5, CSS3, JavaScript, localStorage, Power BI for analysis
